##  Jogo da Cobrinha

##  Integrantes da Equipe
* Nicollas Elidio
* Wallison Mendes

##  Tema Escolhido
Jogos classicos / Arcade

##  Objetivo do Sistema
Divertir o usuario e proporcionar uma experiencia nostalgica pela gameplaay de um jogo classico.

##  Breve Descrição do Funcionamento
 O jogo foi desenvolvido em Python utilizando a biblioteca Pygame. O jogador utiliza as setas do teclado para movimentar a cobrinha pela tela. A cada maçã coletada, a cobrinha aumenta de tamanho. Caso o jogador toque na borda do mapa, ou deixa uma parte da cobrinha encostar nela mesma, o jogo é finalizado e exibe a tela de Game Over.]
